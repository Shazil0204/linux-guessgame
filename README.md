# Guessing Game Script

A simple Bash script that generates a random number within a user-defined range and lets you guess it. The script keeps track of your attempts and congratulates you when you find the correct number.

## Files

- `guessgame.sh` — the main guessing game script.
- `guessgame.1` — optional man page for the script.
## How to Use

1. Open a terminal and navigate to the project folder.
2. Make the script executable:

```bash

chmod +x guessgame.sh

```

## Manual

To read the manual navigate to the folder where you have both files and write 

```bash

man ./guessgame.1

```
